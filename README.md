# 📝 Blog Personal — Ernesto Brugnoli

Sitio web tipo **blog personal** desarrollado con **HTML, CSS y JavaScript**, creado para presentar de forma visual e interactiva información, experiencias, contenido personal y diferentes etapas de la vida de una persona.

El proyecto combina contenido multimedia, navegación entre distintas secciones y un diseño adaptable a diferentes dispositivos.

---

## 🌐 Sobre el proyecto

Este proyecto consiste en el desarrollo de un blog personal dedicado a **Ernesto Brugnoli**.

La página busca reunir diferentes contenidos dentro de un mismo sitio web, presentándolos mediante una interfaz sencilla, visual y fácil de recorrer.

El proyecto comenzó como una página web estática y posteriormente fue evolucionando mediante la incorporación de nuevas secciones, contenido y funcionalidades con JavaScript.

---

## ✨ Características

- 🏠 Página principal.
- 👤 Información personal.
- 🖼️ Contenido visual e imágenes.
- 📖 Diferentes secciones del blog.
- 🎥 Integración de contenido multimedia.
- 📱 Menú adaptado para dispositivos móviles.
- 💻 Diseño responsive.
- ⚡ Interactividad mediante JavaScript.
- 🔗 Navegación entre las diferentes partes del sitio.

---

## 🛠️ Tecnologías utilizadas

### HTML5
Utilizado para definir la estructura y el contenido de las diferentes secciones del sitio.

### CSS3
Utilizado para el diseño visual, distribución de los elementos, adaptación a diferentes tamaños de pantalla y estilos de la página.

### JavaScript
Utilizado para agregar comportamiento dinámico e interactividad a diferentes componentes del sitio.

### Git & GitHub
Utilizados para el control de versiones, almacenamiento del código y publicación del proyecto.

### GitHub Pages
Utilizado para desplegar el sitio web y permitir que pueda ser visitado directamente desde un navegador.

## ▶️ Ejecutar el proyecto localmente

Para ejecutar el proyecto en una computadora:

1. Clonar el repositorio:

```bash
git clone https://github.com/fedebrugnoli12/Ernesto-Brugnoli.git
```

2. Abrir la carpeta del proyecto.

3. Abrir el archivo:

```text
index.html
```

También puede utilizarse **Visual Studio Code** junto con una extensión como Live Server.
